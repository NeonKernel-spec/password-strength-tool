# Contributing to Password Strength Testing Tool

First of all, thank you for taking the time to contribute to this project. Every contribution is appreciated and helps improve the project for everyone.

This project is open for:
- Bug fixes
- UI/UX improvements
- Performance optimization
- Security enhancements
- Documentation updates
- New feature ideas

---

# 🚀 Getting Started

## 1. Fork the Repository

Click the **Fork** button on the top right corner of the repository page.

---

## 2. Clone Your Fork

```bash
git clone https://github.com/NeonKernel-spec/password-strength-tool.git
```

---

## 3. Navigate to the Project Folder

```bash
cd password-strength-tool
```

---

## 4. Create a New Branch

```bash
git checkout -b feature/your-feature-name
```

Example:

```bash
git checkout -b feature/add-password-generator
```

---

## 5. Make Your Changes

You can improve:
- Password analysis logic
- UI design
- Responsiveness
- Accessibility
- Security checks
- Performance

---

## 6. Commit Your Changes

```bash
git commit -m "Add: improved password validation"
```

Use clear and meaningful commit messages.

Examples:
- Fix: mobile responsiveness issue
- Add: dark mode support
- Improve: entropy calculation logic

---

## 7. Push Changes

```bash
git push origin feature/your-feature-name
```

---

## 8. Open a Pull Request

Submit a Pull Request with:
- Clear description
- Screenshots (if UI changes)
- Explanation of improvements

---

# 📌 Contribution Guidelines

Please follow these rules before submitting:

- Write clean and readable code
- Keep the project responsive
- Avoid unnecessary libraries
- Test your changes properly
- Maintain consistent formatting
- Keep commits meaningful

---

You can contribute by adding:

# 🐛 Reporting Bugs

If you find a bug:

1. Open an Issue
2. Explain the problem clearly
3. Add screenshots if possible
4. Mention steps to reproduce the issue
