# 📢 Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it responsibly.

## Please Include:
- Description of the vulnerability
- Steps to reproduce the issue
- Possible impact
- Suggested fix (optional)
- Screenshots or proof-of-concept if available

# 🔐 Security Practices

This project follows basic security-focused development practices:

- Passwords are never stored
- No server-side password processing
- All analysis runs locally in the browser
- No third-party tracking scripts
- No user data collection

---

# ⚠️ Important Notice

This project is designed for educational and demonstration purposes.

The password strength estimation and crack-time calculations are simplified approximations and should not be considered a replacement for professional security auditing tools.

---

# ✅ Recommended Security Practices

Users are encouraged to:
- Use strong and unique passwords
- Avoid common password patterns
- Enable multi-factor authentication (MFA)
- Use password managers
- Never share passwords publicly

---

# 🛡️ Responsible Disclosure

Please do not publicly disclose security vulnerabilities before they have been reviewed and resolved.

Responsible disclosure helps keep users and contributors safe.
